MODULE 4 DEVIN DESKTOP PROMPT PACK
==================================

Purpose
-------

Use these prompts sequentially to implement Module 4 of the container
hardening MVP.

Devin Desktop with GPT-5.4 is only the coding environment used to implement
this repository. Devin is not part of the running hardening product. The
hardening CLI has its own runtime model client and bounded repair harness.

This prompt pack assumes Module 3 is complete and can already:

- Load normalized EZ-Scan findings from an existing run.
- Clone a GitHub Enterprise repository into a run-owned workspace.
- Create a local harden/<run-id> branch.
- Locate supported dependency declarations.
- Create and record a deterministic remediation plan.
- Obtain user approval.
- Use the product's runtime model to update approved files.
- Run git diff --check.
- Leave an uncommitted and unpushed local diff.

Module 4 outcome:

Module 3 approved local diff
-> host Podman build
-> complete build-attempt artifacts
-> bounded build-log-driven repair when necessary
-> successful local candidate image or stop after three attempts
-> verified final diff
-> optional publication approval
-> one commit on harden/<run-id>
-> GitHub Enterprise branch push

Use Prompt 0 first. Then use Prompts 1 through 11 in order. Keep them in the
same Devin task when possible so Devin retains the evolving interfaces.
