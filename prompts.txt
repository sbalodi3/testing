MODULE 3 DEVIN DESKTOP PROMPT PACK
==================================

Purpose
-------

Use these prompts sequentially to implement Module 3 of the container
hardening MVP.

Devin Desktop with GPT-5.4 is only the coding environment used to implement
this repository. Devin is not part of the running hardening product. The
hardening CLI has its own runtime model client and remediation harness.

Module 3 outcome:

existing normalized-findings.json
-> fresh GitHub Enterprise-compatible clone
-> local harden/<run-id> branch
-> direct vulnerability-to-file discovery
-> deterministic remediation plan
-> user approval
-> runtime-model-generated changes to approved files
-> git diff --check
-> auditable local diff

Use Prompt 0 first. Then use Prompts 1 through 10 in order. Keep them in the
same Devin task when possible so Devin retains the evolving interfaces.

MODULE 3 COMPLETION CRITERIA
============================

Module 3 is complete when the CLI can:

1. Load an existing Module 2 run.
2. Clone a GitHub Enterprise repository using workstation Git authentication.
3. Create a local harden/<run-id> branch.
4. Locate direct Critical/High fixed-version findings in requirements and
   container files.
5. Produce and persist a deterministic remediation plan.
6. Ask the user to approve that exact plan.
7. Call the hardening product's runtime model only after approval.
8. Apply only approved allowlisted changes.
9. Run git diff --check.
10. Save the proposal, result, and Git diff.
11. Leave the branch local, uncommitted, and unpushed.

Podman build, bounded repair, Git commit, GitHub Enterprise push, and pull
request creation belong in Module 4.
