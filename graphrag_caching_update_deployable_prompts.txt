PROMPT 2 — CREATE OR UPDATE ONLY gateway/cache.py
===============================================================================

Target file: gateway/cache.py

Create or modify only gateway/cache.py. This module owns generic process-local concurrency and cache coordination. It must not import GraphRAG APIs and must never cache questions or answers.

Implement these public components:

A. GatewayRuntimeSettings

- A frozen dataclass loaded from an optional env mapping or os.environ.
- Fields and defaults:
  query_runtime="cli"
  cache_max_graphs=3
  max_concurrent_queries=3
  query_queue_size=10
  query_queue_timeout_seconds=30.0
  query_timeout_seconds=900.0
- Accept query_runtime only as cli or in_process.
- Validate integers and numbers with clear variable-specific ValueError messages.
- cache_max_graphs and query_queue_size allow 0; max_concurrent_queries requires at least 1; timeouts require values greater than 0.

B. CacheIdentity

- A frozen dataclass containing artifact_revision, settings_fingerprint, and runtime_fingerprint.
- Equality of all three values determines whether a retained graph snapshot is reusable.

C. QueryAdmissionController

- An async context manager slot() enforcing a process-wide active-query limit and a bounded waiting queue.
- When all active slots are used and the waiting queue is full, raise GatewayBusyError immediately.
- Waiting longer than the configured queue timeout raises GatewayBusyError.
- Cancellation and all exceptions must correctly release active/waiting accounting and wake waiters.
- Expose a safe status() result with active, waiting, rejected, and queue-timeout counters. Expose no question text or secrets.

D. CollectionActivityCoordinator

- A process-local per-collection reader/writer coordinator.
- Queries and export operations use reader leases. Artifact/access mutations use writer leases.
- A reader must fail fast with GatewayBusyError if a writer is active or already waiting; this prevents writer starvation and produces a retryable 503.
- A writer waits for current readers to drain and excludes later readers until it completes.
- Waiting counters and active flags must be cancellation-safe and exception-safe.

E. GraphArtifactCache

- A collection-counted bounded LRU cache with async acquire(collection_id, identity, loader) leases.
- max_graphs=0 means execute the loader for every acquisition but retain nothing.
- A hit with the same identity reuses the snapshot and increments an active lease count.
- A miss loads a snapshot once. Concurrent misses for the same collection/revision must be single-flight; they must not perform duplicate loads.
- Different collections should be able to load independently except when global capacity is saturated.
- Identity changes must not replace an actively leased old snapshot. Wait up to the configured timeout, then return GatewayBusyError if it cannot safely reload.
- Evict only idle entries and use least-recently-used order. Never evict an entry with active leases. If every slot is active, wait only up to the configured timeout, then raise GatewayBusyError.
- invalidate(collection_id) removes an idle entry immediately or marks an active entry invalid so it is removed when its final lease exits.
- Track bounded operational counters such as hits, misses, loads, load_failures, evictions, invalidations, and capacity_timeouts.
- summary() returns only process scope, configured capacity, and loaded count. status() may additionally return safe per-entry revision/method/lease/time/memory metadata and counters; it must not return prompts, questions, answers, document content, or secrets.

CRITICAL CANCELLATION REQUIREMENT

Capacity reservations must never leak. Cover the entire period from successful reservation through loader execution and cache-entry installation with ownership tracking and an outer try/finally. If BaseException or cancellation occurs before installation completes—including the narrow interval after loader success but before entry insertion—the reservation must be discarded and all capacity waiters notified. Do not limit cleanup to only an exception raised directly by loader(). A later request must be able to use the slot.

Use asyncio primitives that belong to the running loop. Keep logging useful but free of user questions and secrets.

- Compile/import gateway/cache.py if the current environment has its core dependency.
- Do not create a temporary test file and do not edit tests yet.
- Review every async context manager for cleanup under normal return, exception, timeout, and cancellation.
